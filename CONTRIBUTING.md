# Contributing

This community template is authored and maintained by Diego. Contributions
happen in this repository under [Apache-2.0](LICENSE); it is not listed in a
Mastra catalog.

1. Open an issue to describe a bug, security concern, or proposed change.
2. Create a focused pull request from a branch based on `main`.
3. Include focused tests and keep secrets, databases, generated artifacts, and
   production credentials out of the change.

Security-sensitive changes should describe their affected boundary and any
configuration or cleanup impact. Real-provider and release changes require the
maintainer's explicit review.
